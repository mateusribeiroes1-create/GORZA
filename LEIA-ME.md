# Site Gorza — GitHub Pages

Site estático em HTML, CSS e JavaScript. Não precisa instalar nada nem executar build.

## Ver no computador
Abra `index.html` no navegador. Mantenha os arquivos e a pasta `assets` juntos.

## Publicar no GitHub Pages
1. Extraia este ZIP.
2. Crie um repositório no GitHub (público para usar o Pages no plano gratuito).
3. Clique em **Add file → Upload files** e envie o conteúdo da pasta `gorza`: `index.html`, `style.css`, `script.js` e `assets`. O `index.html` deve ficar na raiz do repositório.
4. Salve em **Commit changes**.
5. Entre em **Settings → Pages → Build and deployment**.
6. Selecione **Deploy from a branch**, branch **main**, pasta **/(root)** e clique em **Save**.
7. Aguarde a publicação. O endereço aparecerá nessa mesma tela, normalmente `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Ajustar o conteúdo
- Textos, produtos, preços, telefone, e-mail e endereço: `index.html`.
- Número do WhatsApp: substitua `5527992523740` nos links de `index.html`. Use país + DDD + número, apenas dígitos. Os contatos funcionam mesmo sem JavaScript.
- Cores, tamanhos e layout: `style.css`.
- Imagens: pasta `assets`. Ao substituir, mantenha o nome ou ajuste o HTML.

## Antes de divulgar
Os contatos, endereço, produtos e preços foram transcritos das imagens de referência; confirme se continuam corretos. As fotos e o logotipo foram recortados das capturas enviadas: substitua pelos originais para obter mais nitidez. A estatística de 1.000 projetos não foi usada por não haver confirmação adicional.

Os botões abrem conversas no WhatsApp com mensagens sobre o serviço ou produto escolhido. Os filtros de produtos e o menu para celular funcionam no navegador. O site não tem carrinho, estoque, pagamento ou painel administrativo.
